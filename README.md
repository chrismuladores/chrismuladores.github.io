# Chrismuladores

<img src="assets/chrismuladores-logo.svg" alt="Logo de Chrismuladores" width="72" />

Laboratorio interactivo para aprender informática mediante simuladores visuales y ejercicios prácticos.

El proyecto reúne herramientas educativas de distintas áreas, actualmente introducción a sistemas operativos e ingeniería de software. Cada simulador permite experimentar, observar resultados y consultar una guía de estudio para comprender los conceptos.

## Simuladores disponibles

- Planificación de procesos: FCFS, SJF y Round Robin con diagramas de Gantt.
- Gestión de memoria: asignación con First Fit, Best Fit y Worst Fit.
- Sistema de archivos: asignación contigua, enlazada e indexada.
- Tipos de sistemas operativos: comparación según escenarios de uso.
- Línea de comandos Windows y Batch Windows.
- Documento ESRE: requisitos, historias de usuario, MoSCoW y trazabilidad.

El sitio se publica con GitHub Pages en la rama `main`.
