Guía rápida
¿Qué es un archivo Batch?
Un archivo Batch es un archivo de texto con extensión .bat o .cmd. Contiene comandos que Windows ejecuta en orden para automatizar tareas repetitivas.
Variables
set NOMBRE=valor guarda un dato. Se consulta usando %NOMBRE%.
Comentarios
Usa rem para documentar el script. El texto no se ejecuta.
Rutas
cd cambia de carpeta, dir la lista y mkdir crea una nueva.
Profundizar: buenas prácticas de automatización
Orden y prueba
Prueba los comandos en una consola antes de automatizarlos. Un script ejecuta las líneas en secuencia, por lo que el orden importa.
Mensajes claros
Usa echo y comentarios para que otra persona pueda seguir el progreso y comprender la finalidad del script.
Operaciones destructivas
Comandos como del eliminan archivos. Este simulador los limita a su entorno virtual; en un equipo real conviene validar rutas y hacer copias.
