        Ramas

        Una rama es una referencia móvil a una línea de commits. Cambiar de rama cambia el contexto de trabajo simulado.

        Guía de estudio

        Flujo básico y conceptos

        Estados

        Modificado vive en el directorio de trabajo. Preparado entra al staging con git add. Confirmado queda registrado con git commit.

        Ramas y merge

        git branch crea una línea de trabajo y git switch cambia a ella. Un merge integra sus commits a la rama destino; los conflictos requieren decisión humana.

        Buenas prácticas

        Escribí commits pequeños y descriptivos, verificá con git status, trabajá en ramas con propósito y actualizá antes de integrar.
