Guía de estudio

¿Qué es CMD?

CMD, o Símbolo del sistema, es un intérprete de comandos de Windows. Permite administrar archivos, navegar por carpetas y automatizar tareas escribiendo instrucciones de texto.

Prompt

Indica la carpeta actual. El comando que escribas se ejecuta dentro de esa ubicación.

Rutas

Usa cd carpeta para entrar, cd .. para volver y cd \ para ir a la raíz de la unidad.

Ayuda

Escribe help para ver los comandos iniciales disponibles en este entorno.

Profundizar: cómo leer comandos
Comando y argumentos

La primera palabra define la acción. Las siguientes son argumentos, por ejemplo mkdir proyectos.

Estado del entorno

Los cambios realizados aquí permanecen mientras no restablezcas el entorno, igual que en una sesión normal de consola.

Seguridad

La consola es completamente virtual: comandos de borrado o copia sólo afectan a sus archivos simulados.
