Guía de estudio

La semántica describe el significado

Una región, un propósito

header presenta una página o sección; nav agrupa enlaces principales; main contiene el contenido dominante y debe ser único.

Contenido relacionado

Usá article cuando el contenido puede existir por sí mismo, como una noticia. section agrupa contenido temático con un encabezado.

Accesibilidad y mantenimiento

Una estructura significativa facilita la navegación con tecnologías de asistencia y permite entender el código sin depender solo de clases visuales.
