¿Cómo leer la simulación?

Usa esta referencia mientras resuelves ejercicios o comparas los resultados de cada estrategia.

FCFS

Primero en llegar

Ejecuta los procesos en orden de llegada. Una vez iniciado, un proceso conserva el CPU hasta terminar.

No expropiativo · simple y predecible.
SJF NP

Ráfaga más corta

Cuando el CPU queda libre, elige entre los procesos disponibles el que necesita menos tiempo de CPU.

No expropiativo · reduce la espera media.
SJF EXP

Tiempo restante más corto

Reevalúa en cada unidad de tiempo. Un proceso nuevo puede interrumpir al actual si tiene menos trabajo restante.

Expropiativo · también se conoce como SRTF.
RR

Round Robin

Los procesos se turnan el CPU durante un quantum. Si no terminan, vuelven al final de la cola.

Expropiativo · útil para sistemas interactivos.

EXPROP.

¿Cuándo se interrumpe?

Un algoritmo expropiativo puede quitar el CPU a un proceso en ejecución. SJF expropiativo lo hace si llega otro proceso con menor tiempo restante; Round Robin lo hace al terminar el quantum.

INANICIÓN

Procesos postergados

SJF puede retrasar mucho procesos largos si siguen llegando trabajos cortos. A este riesgo se le llama inanición.

QUANTUM

Equilibrio en RR

Un quantum muy corto mejora la respuesta, pero produce más cambios de contexto. Uno muy largo hace que Round Robin se parezca a FCFS.

CPU

Uso del procesador

Los espacios vacíos del Gantt representan tiempo ocioso: no hay procesos que hayan llegado y estén listos para ejecutarse.
